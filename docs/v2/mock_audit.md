# V2 Mock Removal Audit

This document tracks the removal of every placeholder, hardcoded state, and mock logic from the frontend and backend, as mandated by the Autonomous Loop Prompt (Step 1).

## Frontend (`frontend/src/app/page.tsx`)

| Component / Logic | Status | Notes |
| :--- | :--- | :--- |
| `mockForecastData` | **REMOVED** | Replaced with real dynamic data fetched from `/api/v1/affordability/check`. |
| `setTimeout` in `handleSend` | **REMOVED** | Replaced with real `fetch()` call to FastAPI. |
| Hardcoded `isAffordable` logic | **REMOVED** | Replaced with backend `decision.status`. |
| Hardcoded `decision` object | **REMOVED** | The Decision Card now renders the exact Pydantic `Decision` model from the backend. |
| Fake `chartData` manipulation | **REMOVED** | Recharts now renders exactly the `days` output generated by the strict 90-day cash flow simulator. |

## Backend (`app/main.py` & `llm/client.py`)

| Component / Logic | Status | Notes |
| :--- | :--- | :--- |
| `_call_llm` returning string literal | **REMOVED** | Now uses actual HTTP requests to Ollama API `http://localhost:11434/api/generate`. |
