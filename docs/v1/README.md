# Fintech Guru: Buy or Wait? (V1)

## Hackathon Objective
The goal of the HackerRank Orchestrate 24-hour hackathon (September 2026) was to build an AI-powered financial agent that decides whether a user can safely afford a requested expense (e.g., "Can I afford this laptop?"). 

The agent had to output a personalized payment recommendation (Full Payment, Partial Payment, Installments, Wait, or Not Recommended) by evaluating:
- Current balances
- Recurring expenses and income
- Pending and failed payments
- Multicurrency conversions
- Image and text message extraction

## V1 Hackathon Submission
This frozen V1 codebase represents the exact submission that achieved **Rank #702** out of approximately 3,000 participants. It successfully implemented the requirements under a severe time constraint, utilizing a hybrid deterministic-agentic architecture. 

It is preserved here for reproducibility and reference. No further modifications will be made to V1.
